# AI Hub - Kho Công Cụ AI 🚀

Trang web tổng hợp các công cụ AI hay nhất năm 2026 giúp tối ưu công việc và sáng tạo.

## 🔗 Demo Trực Tuyến
Bạn có thể trải nghiệm trang web tại: [AI Hub Live](https://skibidi2505.github.io/Ai-Warehouse/)

## ✨ Tính Năng
- Tìm kiếm công cụ AI theo từ khóa.
- Lọc AI theo mức phí (Miễn phí, Freemium, Trả phí).
- Chế độ Giao diện Sáng/Tối (Light/Dark mode).
- Lưu công cụ yêu thích vào trình duyệt.

## 🛠️ Công Nghệ Sử Dụng
- HTML5 / JavaScript (ES6+)
- Tailwind CSS (CDN)
- FontAwesome Icons
